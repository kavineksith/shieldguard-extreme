🚫 Blocking
🚫
Ad Blocking
Blocks 50+ ad networks at the network layer via declarativeNetRequest. Zero JavaScript overhead — blocked before any bytes hit the wire.
👁️
Tracker Blocking
Stops analytics beacons, session recorders (Hotjar, FullStory, Clarity), attribution SDKs, pixel trackers, and data-broker scripts.
🪟
Overlay & Paywall Removal
Real-time DOM sweep + MutationObserver removes cookie banners, GDPR dialogs, subscribe gates, age-gates, and soft/hard paywalls.
🎨
Cosmetic CSS Filters
Injects CSS rules to hide known ad containers and paywall elements that slip past network blocking — a second line of defence.
🔮 Privacy
🔮
Fingerprint Protection
Injects imperceptible per-session noise into Canvas getImageData/toDataURL, WebGL vendor/renderer strings, AudioContext frequency data, and Navigator hardware hints.
🤖
Anti-Adblock Bypass
Spoofs window.canRunAds, adsEnabled, and other detection globals. Creates a fake bait "adsbox" element with overridden geometry so detector scripts believe ads loaded normally.
🔗
Strip Tracking Parameters
Silently removes utm_*, fbclid, gclid, msclkid, ttclid, and 15+ other tracking params from the URL via history.replaceState — no reload needed.
🔄
Scroll Restoration
Forcibly undoes overflow:hidden and position:fixed body locks that paywall scripts inject to prevent scrolling without subscribing.

Custom Rules

Add your own URL filter patterns — same syntax as uBlock Origin

📖 Syntax Reference
||example.com^ — block all requests to example.com
||cdn.ads.com/script.js — block a specific path
*tracking* — block any URL containing "tracking"
||safe.com^ — pattern (@@prefix to whitelist instead)
# Comment lines are ignored
@@||allowed.example.com^ — exception / allow rule
